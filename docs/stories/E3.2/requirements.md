# E3.2: Preview Next-Round Roster from Saved Decisions

- **Epic:** E3 Round Setup and Candidate Roster
- **Priority:** P1 (proposed)
- **Workflow status:** Backlog; not formally accepted
- **User story:** As an administrator, I want to review which candidates will carry forward before I create the next draft.

## Acceptance Criteria
- Preview includes only candidates marked Advanced in the preceding revealed round.
- Candidates marked Eliminated or Elected are visibly excluded, with no implication that votes alone automatically decide a single-opening outcome.
- Changes to saved decisions refresh the preview consistently.

## Scope and Dependencies
Read-only next-roster preview. Depends on US-012 and saved decisions in E5.2; relates to E5.3.

## Relevant Decisions
For a single opening, administrator/committee decisions control outcomes; vote count recommendations do not automatically decide. Advanced candidates form the later-round roster.

## Implementation Notes and Limitations
Backlog says later-round rosters use candidates marked Advanced and the duplicate name picker was removed. Preview remains follow-up UX.
