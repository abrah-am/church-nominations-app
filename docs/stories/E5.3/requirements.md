# E5.3: Provide a Reviewed-Results Handoff to the Next Round

- **Epic:** E5 Results Review and Candidate Decisions
- **Priority:** P1 (proposed)
- **Workflow status:** Backlog; not formally accepted
- **User story:** As an administrator, I want to see the number and names of candidates advancing before configuring the next round.

## Acceptance Criteria
- After decisions are saved, show the Advanced roster and clearly indicate whether another round can be configured.
- If no candidates advance, explain the state and available resolution instead of presenting an unusable setup form.
- Selection-count bounds use the previewed next-round roster.

## Scope and Dependencies
Post-decision handoff from results to round setup. Depends on E5.2 decision persistence and E3.2 roster preview. No automatic roster changes beyond saved decisions.
